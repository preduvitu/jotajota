## Sobre o projeto

O **JotaJota Buffet** atende todo o Distrito Federal, levando gastronomia de qualidade, garçons, louças e bebidas para o local escolhido pelo cliente — seja sua casa, um espaço de eventos ou qualquer outro ambiente.

Este repositório contém a landing page do buffet, desenvolvida para apresentar os serviços, galeria de eventos, avaliações de clientes e facilitar o contato via WhatsApp.

## Rodando localmente

Você precisa ter o [Bun](https://bun.sh) instalado.

```sh
git clone https://github.com/preduvitu/jotajota.git
cd jotajota
bun install
bun run dev
```

Acesse em: [http://localhost:8080](http://localhost:8080)
